# Anàlisi de l’arquitectura

Responeu breument:

1.   Per què el servidor `SRV-AD-01` necessita una adreça IP fixa?
  
   Perquè si la IP canviés per DHCP, els clients no sabrien a quina adreça buscar el controlador de domini ni el servidor DNS per autenticar-se.
2.   Per què els clients del domini han d’utilitzar un servidor DNS capaç de resoldre la zona d’Active Directory?
  
  Perquè Active Directory necessita els registres DNS per tal que els equips de la xarxa puguin trobar on està el controlador de domini.
3.   Què passaria si `SRV-AD-01` estigués apagat?
    
    Els usuaris no podrien iniciar sessió al domini, no es resoldrien els noms de la xarxa local i es resoldria malament l'accés a les carpetes compartides i recursos.
4.   Per què un únic controlador de domini és acceptable al laboratori però insuficient en una empresa real?
    
    Perquè a classe serveix per fer proves, però en una empresa si el servidor cau, tota la xarxa es queda penjada. Es necessita un segon controlador de domini per imprevistos a fallades.
5.   Per què els departaments no s’han creat com a dominis diferents?
    
    Perquè crear múltiples dominis complica la gestió de la xarxa. És molt més senzill i eficient organitzar els departaments fent servir Unitats Organitzatives (OU) dins del mateix domini.

Justifiqueu breument l’ordre escollit.  

Preparar la xarxa del servidor (posar IP fixa, configurar el nom de l'equip...).

Instal·lar AD DS (afegir el rol d'Active Directory al Windows Server).

Crear el bosc i el domini (musiccloud.local, pujant el servidor a Controlador de Domini).

Comprovar el DNS (assegurar-nos que resol bé i s'han creat els registres necessaris).

Crear les unitats organitzatives (les carpetes o OUs per separar els departaments).

Crear els grups (per gestionar els permisos de manera conjunta).

Crear els usuaris (els comptes de les persones que treballaran).

Assignar els usuaris als grups (posar cada persona al seu grup corresponent).

Unir el client al domini (connectar l'ordinador de l'usuari a musiccloud.local).

Comprovar el funcionament del domini (provar d'iniciar sessió des del client amb un usuari de domini).


Justificacio:

Primer preparem el servidor i instal·lem Active Directory (passos 1-3). Després comprovem el DNS, ja que el directori el necessita per funcionar (pas 4). A continuació, creem l'estructura de l'empresa: OUs, grups i usuaris (passos 5-8). I per acabar, unim els clients i comprovem que tot funciona correctament(passos 9-10).
