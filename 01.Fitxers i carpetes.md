# Treballar amb fitxers i carpetes

**Situació:** encara no hem estudiat les ordres de PowerShell per treballar amb fitxers i carpetes. Les haurem de descobrir utilitzant les eines d'ajuda de PowerShell.
**1. Buscar ordres**

Busca cmdlets que continguin la paraula `Item`:

```
Get-Command *Item*
```

Observa les ordres que apareixen.

Intenta identificar quina ordre podria servir per:

- crear un element;
- eliminar un element;
- canviar el nom d'un element;
- copiar un element;
- moure un element.

**Resposta**

| Acció | Cmdlet | Explicació |
|---|---|---|
| Crear un element | `New-Item` | Crea un fitxer, una carpeta o un altre element nou en una ruta. Amb `-ItemType File` o `-ItemType Directory` s'indica què es crea. |
| Eliminar un element | `Remove-Item` | Esborra fitxers, carpetes o altres elements. Amb `-Recurse` esborra també el contingut d'una carpeta. |
| Canviar el nom d'un element | `Rename-Item` | Canvia el nom d'un element sense canviar-lo de lloc. Necessita `-Path` (element actual) i `-NewName` (nou nom). |
| Copiar un element | `Copy-Item` | Fa una còpia d'un element cap a una altra ubicació; l'original es manté. Amb `-Recurse` copia carpetes amb el seu contingut. |
| Moure un element | `Move-Item` | Trasllada un element d'una ubicació a una altra; l'original desapareix del lloc d'origen. També serveix per renombrar si es canvia el nom en la destinació. |

**Exemples**

```powershell
New-Item -Path .\prova.txt -ItemType File
Rename-Item -Path .\prova.txt -NewName prova2.txt
Copy-Item -Path .\prova2.txt -Destination C:\Temp\
Move-Item -Path .\prova2.txt -Destination C:\Documents\
Remove-Item -Path .\prova2.txt
```

Nota: la sortida de `Get-Command *Item*` també mostra altres cmdlets, com `Get-Item`, `Set-Item`, `Clear-Item` o `Invoke-Item`, que serveixen per obtenir, modificar, buidar o obrir elements.


**2. Investigar una ordre**

Sense executar-la encara, consulta què fa:

```
Get-Help New-Item
```

Respon:

- Per a què serveix `New-Item`?
- Quina estructura té l'ordre?

Consulta alguns exemples:

```
Get-Help New-Item -Examples
```

**Resposta**

**Per a què serveix `New-Item`?**

Serveix per crear un element nou: un fitxer o una carpeta.

**Quina estructura té l'ordre?**

```
New-Item -Path <ruta> -ItemType <tipus> -Name <nom>
```

| Part | Què vol dir |
|---|---|
| `New-Item` | L'ordre (crear un element) |
| `-Path` | On el vull crear (la ruta) |
| `-ItemType` | Què vull crear: `File` (fitxer) o `Directory` (carpeta) |
| `-Name` | El nom que li vull posar |

Les parts que comencen amb `-` es diuen **paràmetres**: donen detalls a l'ordre.

**Exemples** 

```powershell
# Crear un fitxer
New-Item -Path . -Name "prova.txt" -ItemType File

# Crear una carpeta
New-Item -Path . -Name "MevaCarpeta" -ItemType Directory
```

El punt `.` vol dir "la carpeta on estic ara".


## 3. Descobrir un paràmetre

Consultem el paràmetre `-ItemType`:

```powershell
Get-Help New-Item -Parameter ItemType
```

`-ItemType` indica el tipus d'element que volem crear.

Per crear una carpeta:

```powershell
New-Item -ItemType Directory -Name Prova
```

Comprovem que s'ha creat:

```powershell
Get-ChildItem
```

La carpeta `Prova` apareix a la llista.


**4. Nou repte**

Ara necessites saber com **canviar el nom de la carpeta**, però no coneixes l'ordre.

Utilitza:

```

```

i després consulta l'ajuda de l'ordre que creguis adequada.

L'objectiu és arribar a descobrir:

```
Rename-Item
```

i consultar:

```
Get-Help Rename-Item -Examples
```

Estàs administrant un servidor Windows i necessites consultar informació de la seva configuració de xarxa.

Encara no coneixes les ordres de PowerShell relacionades amb xarxa.

La teva feina és descobrir-les utilitzant principalment:

```

Get-Help
```

No pots buscar les respostes a Internet.
